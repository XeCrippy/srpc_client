# SRPC Client documentation

These guides describe how to consume the prebuilt SRPC Client library from a
Windows C++ application.

1. [Getting started](getting-started.md)
2. [Client guide](client-guide.md)
3. [Memory and RPC](memory-and-rpc.md)
4. [Files and screenshots](files-and-screenshots.md)
5. [Debugging](debugging.md)

All examples assume C++20 and use the `srpc` namespace. The declarations in
the distributed `include/srpc` directory are the authoritative API reference
for the exact release version.
